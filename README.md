# Sai Sagar's Portfolio

A modern, dark-themed portfolio website with a cool coding animation background.

## Prerequisites

Before you begin, ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v14 or higher)
- npm (comes with Node.js)

## Setup Instructions

1. Install Node.js from [https://nodejs.org/](https://nodejs.org/)

2. Clone this repository or download the files

3. Open a terminal in the project directory

4. Install dependencies:
```bash
npm install
```

5. Start the development server:
```bash
npm run dev
```

6. Open your browser and visit `http://localhost:5173`

## Features

- Dark theme with coding animation background
- Responsive design
- Interactive particle effects
- Skill cards with hover animations
- Modern UI with gradient text effects
